# amiz-site

かぎ針編み図アプリ **Amiz** のサポートページとプライバシーポリシー。

GitHub Pages で公開している。App Store Connect の「サポート URL」「プライバシーポリシー URL」に登録するために必要（どちらも必須項目）。

| ファイル | 役割 | 公開先 |
|---|---|---|
| `index.html` | サポートページ。お問い合わせフォームへの導線、よくある質問 | `/` |
| `privacy.html` | プライバシーポリシー | `/privacy.html` |

アプリ本体（非公開リポジトリ `ITOakr/Amiz`）の設定画面と、Pro の案内画面からリンクしている。
